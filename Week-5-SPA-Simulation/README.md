# 🚀 TechSphere SPA Simulation

A modern **Single Page Application (SPA)** simulation developed using **HTML5, CSS3, and Vanilla JavaScript** as part of the **Frontend Web Developer Internship - Week 5**.

---

## 📌 Project Overview

TechSphere is a responsive SPA that dynamically loads content without refreshing the page. It demonstrates client-side routing, DOM manipulation, browser history management, and a modern user interface.

---

## ✨ Features

- 🏠 Home Page
- 👨‍💼 About Page

- 📞 Contact Page
