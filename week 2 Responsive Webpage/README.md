# 🌐 Week 2 - Responsive Business Website

## 📌 Project Overview

This project was developed as part of the **Week 2 Internship Task: Implementation of Responsive Web Design**.

The objective of this project is to build a modern, fully responsive business website from scratch using **HTML5**, **CSS3**, and **JavaScript**. The website adapts seamlessly to different screen sizes, including desktops, laptops, tablets, and smartphones.

# 📱 Responsive Design

This website is designed using modern responsive web development techniques.

The layout automatically adapts to multiple devices including:

- Desktop
- Laptop
- Tablet
- Mobile

Media Queries have been implemented to ensure an excellent user experience on different screen sizes.
