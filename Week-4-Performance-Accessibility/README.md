# 1. Objective

The objective of this task was to optimize an existing responsive business website by improving its performance, accessibility, semantic HTML structure, and overall user experience. The project focused on making the website faster, more accessible to users with disabilities, and compliant with modern web development best practices.

---

# 2. Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Visual Studio Code
- Git & GitHub
- Google Chrome
- Lighthouse (Performance Testing)

---

# 3. Performance Optimizations

The following performance improvements were implemented:

- Optimized HTML structure
- Reduced unnecessary CSS code
- Used CSS Variables for better maintainability
- Optimized JavaScript event handling
- Implemented Lazy Loading for images
- Reduced DOM manipulation where possible
- Optimized responsive layout
- Improved rendering performance
- Faster page scrolling and smoother animations

---

# 4. Accessibility Improvements

The website was enhanced using modern accessibility practices including:

- Semantic HTML5 elements
- Proper heading hierarchy
- Descriptive ALT text for images
- ARIA Labels
- ARIA Expanded attribute
- Keyboard Navigation Support
- Focus Indicators
- Accessible Contact Form
- Improved Color Contrast
- Responsive Design for all screen sizes

---

# 5. Semantic HTML Improvements

The webpage structure was improved by using semantic HTML elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

These elements improve readability, SEO, and compatibility with screen readers.
