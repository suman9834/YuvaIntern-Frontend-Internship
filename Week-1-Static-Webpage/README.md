# 🌐 Suman Tech - Modern Responsive Landing Page

## 📌 Project Overview

**Suman Tech** is a modern and responsive landing page developed as part of the **Week 1 Internship Task: Transforming Wireframes into Static Web Pages**.

The objective of this project is to demonstrate the ability to convert a wireframe into a fully functional static website using **HTML5** and **CSS3**. The webpage follows semantic HTML practices, clean CSS architecture, and responsive design principles to provide an optimal user experience across different devices.
