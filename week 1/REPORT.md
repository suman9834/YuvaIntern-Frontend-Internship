# 1. Objective

The objective of this task was to design and develop a fully responsive static landing page using **HTML5** and **CSS3**. The project focused on converting a wireframe concept into a clean, professional, and responsive webpage while following semantic HTML practices and modern CSS techniques.

---

# 2. Project Description

The project, **Suman Tech – Modern Responsive Landing Page**, was created to represent a fictional web development company. The website showcases a professional business landing page with multiple sections designed to provide users with an engaging browsing experience.

The webpage includes:

- Responsive Header & Navigation
- Hero Section
- Features Section
- About Section
- Services Section
- Contact Form
- Footer

The entire project was developed using only **HTML5** and **CSS3** without using JavaScript.

---

# 3. Design Decisions

The following design decisions were implemented during development:

- Used semantic HTML5 elements for better accessibility and SEO.
- Selected a modern blue color palette to create a clean and professional appearance.
- Integrated Google Fonts (Poppins) for improved typography.
- Used Font Awesome icons for better visual representation.
- Applied Flexbox and CSS Grid for responsive layouts.
- Used a full-screen hero background image with an overlay to improve readability.
- Designed modern cards with rounded corners and hover animations.
- Maintained consistent spacing and alignment across all sections.

---

# 4. Layout Strategy

Different CSS layout techniques were used throughout the project.

## Header

A responsive navigation bar was created using **Flexbox** to align the logo and navigation links.

## Hero Section

The Hero section uses a full-screen background image with a dark overlay. Flexbox was used to center the content both vertically and horizontally.

## Features Section

CSS Grid was used to create responsive feature cards that automatically adjust according to screen size.

## About Section

A two-column layout was created using CSS Grid, displaying an image alongside descriptive content.

## Services Section

Responsive service cards were designed using CSS Grid to maintain consistency across different devices.

## Contact Section

A simple and user-friendly contact form was developed with responsive input fields and a call-to-action button.

# 7. Challenges Faced

## Challenge 1

Creating a layout that works well on all screen sizes.

### Solution

Used Flexbox, CSS Grid, and Media Queries to build a fully responsive layout.

---

## Challenge 2

### Solution

Applied uniform margins, padding, and reusable CSS classes to ensure consistency.

---

## Challenge 3

### Solution

Separated CSS into logical sections using comments and meaningful class names to improve readability and maintainability.
